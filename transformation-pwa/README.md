# Трансформация

**Сайт:** https://transformation-pwa.netlify.app/

Мобильное приложение (PWA) для саморазвития: привычки, спорт и здоровье, знания и английский. Работает без интернета после первого открытия. Данные хранятся только на вашем телефоне.

## Установка на телефон

Откройте адрес сайта (его выдал Netlify) в браузере телефона.

- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (только Safari):** кнопка «Поделиться» → «На экран Домой».

После установки приложение запускается с иконки как обычное. Кнопки с подсказками есть и в «Ещё» → «Настройки».

## Первый запуск

1. Введите имя.
2. Оцените 6 сфер жизни от 1 до 10 (колесо баланса).
3. Поставьте 1-3 цели на 90 дней.

Дальше основной экран «Сегодня»: три приоритета дня, сводка по разделам, XP и достижения.

## Разделы

| Раздел | Что внутри |
|---|---|
| Сегодня | Приоритеты дня, сводка, уровень и XP, достижения |
| Привычки | Отметка одним тапом, серии, календарь за 5 недель, подсказка «после X → привычка» |
| Спорт | 3 программы без оборудования, таймер отдыха, история, рекорды |
| Знания | Карточки с интервальным повторением (алгоритм SM-2), импорт строк `вопрос;ответ` |
| Здоровье | Вода, сон, вес, настроение, графики 7 и 30 дней |
| Челлендж | 12 недель: цель на неделю в XP, график недель, список недель (меню «Ещё») |
| Подсказки | Правила по вашим данным: серия под угрозой, пропуски, вода и сон за 7 дней, цель челленджа (меню «Ещё»). Это не ИИ и не медицинские советы |
| Активность | График XP за 7, 14 и 30 дней и лента действий (меню «Ещё») |
| Языки | 12 уроков английского уровня A1, кнопка «добавить слова в карточки» |
| План | Колесо баланса, цели с шагами, недельный обзор по воскресеньям |
| Настройки | Тема (по умолчанию тёмная), имя, экспорт и импорт данных, напоминания |

## Резервная копия данных

Данные живут в браузере на конкретном адресе сайта. Очистка данных браузера или смена адреса удалит их.

- **Сохранить:** «Ещё» → «Настройки» → «Экспорт данных». Скачается JSON-файл.
- **Восстановить:** там же «Импорт данных», выберите файл.

Делайте экспорт перед сменой адреса сайта, переустановкой браузера и сбросом.

## Как обновить сайт на Netlify

1. Возьмите новую версию папки `transformation-pwa` (без папок `tests` и `docs`, `index.html` должен лежать в корне).
2. На Netlify откройте ваш сайт и перетащите папку в раздел деплоев (Deploys). Точные названия кнопок могут отличаться, интерфейс Netlify меняется.
3. На телефоне новая версия может появиться не сразу: приложение отдаёт сохранённые файлы и обновляет их в фоне. Закройте и откройте приложение один-два раза. Если изменили логику `sw.js`, увеличьте `VERSION` в его первой строке.

## Отклик

Короткая вибрация при нажатиях и начислении XP (Android Chrome). На iPhone в Safari вибрация браузером не поддерживается. Выключается в «Настройки» → «Отклик».

## Ограничения

- **Напоминания** надёжно работают, только пока приложение открыто или в фоне. Серверных push-уведомлений нет, при закрытом приложении (особенно на iPhone) они могут не прийти.
- **Один телефон, один набор данных.** Синхронизации между устройствами нет, переносите вручную через экспорт.
- Приложение не заменяет врача и тренера. Рекомендации по сну, нагрузке и весу общие.
- Тексты уроков и упражнений проверялись выборочно. Если заметите ошибку в переводе или технике, исправьте в `js/data/`.
- Проверялось в эмуляции Chromium (390px), не на всех реальных устройствах.

## Для разработчика

Без сборки: обычные ES-модули, файлы лежат как есть.

```bash
# запуск локально (нужен любой статический сервер)
python3 -m http.server 8000      # затем http://localhost:8000

# тесты
node tests/srs.test.mjs          # алгоритм повторения
node tests/e2e.mjs               # сквозной сценарий (нужен playwright)
```

Структура: `js/store.js` (состояние в localStorage), `js/app.js` (маршруты), `js/views/*.js` (разделы), `js/data/` (упражнения и уроки), `sw.js` (офлайн), `docs/METHODOLOGY.md` (на чём основаны решения, часть источников помечена как непроверенная).

Если Python отдаёт `.css` как `text/plain` (бывает в некоторых окружениях), страница выглядит без стилей. Используйте сервер с правильными MIME-типами.
